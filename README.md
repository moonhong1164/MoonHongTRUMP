# MoonHongTRUMP

트럼프 카드 52장(+선택 조커)으로 보는 카드점 사이트입니다.

- 배열 9가지: 오늘의 한 장, 예/아니오, 오늘의 운세, 오라클, 과거·현재·미래, 다섯 장 십자, 진로, 꿈 징검다리, 일주일 운세(카토만시 25장)
- 특수 카드점: 몬테카를로(연애점·소원점), 피라미드
- 카드 도감, 읽는 법, 카드 이야기

빌드 없는 정적 사이트입니다. `index.html`을 열거나 아무 정적 서버로 띄우면 됩니다.
